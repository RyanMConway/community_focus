# SEO Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add comprehensive SEO metadata, a sitemap, and robots.txt so Google indexes all 31 communities and key pages with meaningful titles and descriptions.

**Architecture:** Next.js App Router handles SEO natively — static pages export a `metadata` object, the dynamic `[slug]` page uses `generateMetadata()` to fetch community data from NeonDB. A `sitemap.ts` file auto-generates `/sitemap.xml` listing all community slugs. No third-party libraries needed.

**Tech Stack:** Next.js 16 App Router (`metadata` API, `generateMetadata`, `MetadataRoute.Sitemap`), NeonDB (`pool` from `@/lib/db`).

---

## Background: How Next.js Metadata Works

Every `page.tsx` can export either:

```ts
// Static (for fixed pages)
export const metadata: Metadata = {
  title: 'Page Title | Community Focus of NC',
  description: '...',
  openGraph: { ... },
}

// Dynamic (for [slug] pages — can fetch DB)
export async function generateMetadata({ params }): Promise<Metadata> {
  const community = await getCommunity(params.slug);
  return { title: `${community.name} | Community Focus of NC`, ... }
}
```

The root `layout.tsx` sets a **template** so individual page titles get the site name appended automatically without repeating it in every file.

### Task 4: Dynamic Community Page Metadata

**Files:**
- Modify: `src/app/communities/[slug]/page.tsx`

This is the most valuable SEO task — 31 unique community pages, each indexed by name and city.

**Step 1: Read the existing file**

Open `src/app/communities/[slug]/page.tsx`. There is already a DB query function (e.g. `getCommunity(slug)`). We'll reuse that same function in `generateMetadata`.

**Step 2: Add the `generateMetadata` export**

Add this above the default page component. It must be an `async` function since it queries the DB:

```ts
import type { Metadata } from 'next';

export async function generateMetadata(
  { params }: { params: { slug: string } }
): Promise<Metadata> {
  const community = await getCommunity(params.slug);

  if (!community) {
    return { title: 'Community Not Found' };
  }

  const title = community.name;
  const description = community.description
    ? `${community.description} Managed by Community Focus of NC.`
    : `${community.name} in ${community.city}, NC — managed by Community Focus of NC. Access documents, contact your manager, and stay connected with your community.`;

  return {
    title,
    description,
    openGraph: {
      title: `${community.name} | Community Focus of NC`,
      description,
      ...(community.image_url && { images: [{ url: community.image_url }] }),
    },
  };
}
```

**Step 3: Verify**

Navigate to `http://localhost:3000/communities/churton-grove` (or any community). View page source and confirm `<title>Churton Grove Homeowners Association | Community Focus of NC</title>` appears.

**Step 4: Commit**

```bash

git commit -m "feat(seo): add generateMetadata for dynamic community pages"
```

### Task 5: Sitemap

**Files:**
- Create: `src/app/sitemap.ts`

This file is served automatically at `/sitemap.xml`. It tells Google every URL that exists on the site, including all 31 community pages.

**Step 1: Create the file**

```ts
import type { MetadataRoute } from 'next';
import pool from '@/lib/db';

export const dynamic = 'force-dynamic';

async function getCommunitySlugList(): Promise<string[]> {
  const client = await pool.connect();
  try {
    const res = await client.query(
      "SELECT slug FROM communities WHERE slug != 'global' ORDER BY name ASC"
    );
    return res.rows.map((r: { slug: string }) => r.slug);
  } finally {
    client.release();
  }
}

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const slugs = await getCommunitySlugList();
  const base = 'https://www.communityfocusnc.com';

  const staticRoutes: MetadataRoute.Sitemap = [
    { url: base, lastModified: new Date(), changeFrequency: 'monthly', priority: 1 },
    { url: `${base}/communities`, lastModified: new Date(), changeFrequency: 'weekly', priority: 0.9 },
    { url: `${base}/services`, lastModified: new Date(), changeFrequency: 'monthly', priority: 0.8 },
    { url: `${base}/about`, lastModified: new Date(), changeFrequency: 'monthly', priority: 0.7 },
    { url: `${base}/reviews`, lastModified: new Date(), changeFrequency: 'weekly', priority: 0.7 },
    { url: `${base}/vendors`, lastModified: new Date(), changeFrequency: 'monthly', priority: 0.6 },
    { url: `${base}/contact`, lastModified: new Date(), changeFrequency: 'yearly', priority: 0.6 },
    { url: `${base}/resources`, lastModified: new Date(), changeFrequency: 'monthly', priority: 0.5 },
    { url: `${base}/get-proposal`, lastModified: new Date(), changeFrequency: 'yearly', priority: 0.5 },
  ];

  const communityRoutes: MetadataRoute.Sitemap = slugs.map((slug) => ({
    url: `${base}/communities/${slug}`,
    lastModified: new Date(),
    changeFrequency: 'weekly' as const,
    priority: 0.8,
  }));

  return [...staticRoutes, ...communityRoutes];
}
```

**Step 2: Verify**

Visit `http://localhost:3000/sitemap.xml`. You should see XML with all static routes plus one `<url>` entry per community slug.

**Step 3: Commit**

```bash
git add src/app/sitemap.ts
git commit -m "feat(seo): add dynamic sitemap including all community pages"
```

### Task 6: Robots.txt

**Files:**
- Create: `src/app/robots.ts`

Tells search engines to index all public pages but block `/admin`.

**Step 1: Create the file**

```ts
import type { MetadataRoute } from 'next';

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      {
        userAgent: '*',
        allow: '/',
        disallow: '/admin',
      },
    ],
    sitemap: 'https://www.communityfocusnc.com/sitemap.xml',
  };
}
```

**Step 2: Verify**

Visit `http://localhost:3000/robots.txt`. Should show:
```

Allow: /
Disallow: /admin

Sitemap: https://www.communityfocusnc.com/sitemap.xml
```

**Step 3: Commit**

